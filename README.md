# Alejandro Guerra

I'm a Colorado College student studying computer science and a Machine Learning Fellow. I build Python tools for AI-assisted development, with a focus on task permissions, verification, and recovery when work is interrupted.

## Selected work

### [Governed Meta-Factory](https://github.com/ale-Gdev/Governed-Meta-Factory)

I build and use a private workflow system that connects approved tasks, implementation, checks, and review. The public repository is an earlier foundation, with a Python runtime, scope and approval checks, evidence handling, and tests. It is a workflow tool, not an operating-system sandbox.

### [Bounded Admission](https://github.com/ale-Gdev/bounded-admission)

A deterministic Python checker that evaluates declared workflow dependencies against supplied rules and explains its decisions. The public examples include accepted, rejected, and malformed inputs. It checks a supplied model; it does not execute the workflow. My related private development prototype explores artifact verification and recovery using synthetic tasks.

## How I work

I use Codex and Claude for research, implementation, and testing. I set requirements, review results, and test failure cases against the behavior I intended.

I'm interested in connecting with people building developer tools and practical AI-assisted workflows.
